# GlowCasino

Премиальный плагин на казино для серверов Minecraft (Paper 1.21+, Java 21).

## Особенности
- **3 азартных режима**:
  - **Алмазная рулетка**: классическая рулетка с барабаном и множителями на ценные ресурсы.
  - **Кладоискатель**: интерактивное поле 5x5 с поиском сокровищ и динамитом.
  - **Конные скачки**: забег 4 лошадей с выбором из 15 уникальных мастей и живой анимацией на дорожках.
- **Мультивалютность**:
  - Монеты (Vault Economy)
  - Алмазы (инвентарь)
  - Серебро (железные самородки)
  - Незерит (незеритовые слитки)
- **Управление ставками**:
  - ЛКМ / ПКМ (+ / - шаг)
  - Shift+ЛКМ / Shift+ПКМ (+ / - крупный шаг)
  - Q (максимальная ставка)
- **Полная кастомизация**: все тексты, множители, звуки и шансы настраиваются в `messages.yml` и `config.yml`.
- **Adventure Component API**: поддержка RGB, MiniMessage и чистое форматирование без курсива.

## Команды и права
- `/casino` — открыть главное меню казино (право `glowcasino.use`).
  - Алиасы: `/glowcasino`, `/kzk`, `/kasino`.
- `/casino reload` — перезагрузить конфигурацию и сообщения (право `glowcasino.admin.reload` или `glowcasino.admin`).

## Сборка
```bash
mvn clean package
```
Готовый .jar файл будет создан в директории `target/GlowCasino-1.0.0.jar`.
